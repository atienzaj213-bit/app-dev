# My Favorite Series: Stranger Things

## About the Show
**Stranger Things** is an American science fiction horror drama television series created by the Duffer Brothers. Set in the 1980s in the fictional town of Hawkins, Indiana, it follows a group of friends and their supernatural adventures.

> "Friends don't lie." — Eleven
